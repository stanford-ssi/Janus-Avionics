# Janus-Avionics
Welcome to the Stanford Student Space Initiatve Satellite Avionics Team! This is our official github repository. Here, you can find any piece of information about our newest satellite, Project Janus, that you might need.

This repository covers everything from trainings on how to learn KiCad to the individual schematic files for Janus. If you ever miss a meeting, you'll always be able to check back here to find or access what you need.

Please make sure to check this repository if you miss a meeting, need to work on the satellite, or quite literally do anything. on this team.

## Repository Structure
This repository will be the primary place to find trainings, meeting notes, KiCad schematics, repositories, etc. Literally everything you need will be in this repository. The repository is broken down into the following folders:

```bash
.
├── assembly/ # Contains all procedures and documentation relating to board assembly \ board integration
├── design/ # Contains all documentation relating to the satellite design
├── fmus/ # Contains all Functional Modular Units (FMUs)
├── research/ # Contains all reesarch related to the satellite design
├── standards/ # Contains all standards that must be followed during research, design, assembly, testing, and documentation.
├── testing/ # Contains all documentation of board testing for work on the satellite or on FMUs
└── trainings/ # Contains all team trainings (Markdown, Slides, PDF's, etc.) necessary for necessary avionics skills.
```
