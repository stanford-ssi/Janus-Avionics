# Janus-Avionics
Welcome to the Stanford Student Space Initiatve Satellite Avionics Team! This is our official github repository. Here, you can find any piece of information about our newest satellite, Project Janus, that you might need.

This repository covers everything from trainings on how to learn KiCad to the individual schematic files for Janus. If you ever miss a meeting, you'll always be able to check back here to find or access what you need.

Please make sure to check this repository if you miss a meeting, need to work on the satellite, or quite literally do anything. on this team.
