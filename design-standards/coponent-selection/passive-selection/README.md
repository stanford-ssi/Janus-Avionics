# Passive Selection
The SSI Satellite Avionics Team uses JLCPCB for almost every custom-designed PCB we design and fabricate. Thus, our component selection is entirely dependent on what is most available and most accessible using JLCPCB's stocks (Using LCSC components)

## Selection Considerations & Design Requirements
**Please read the component selection guidelines in the component-select [README](../../coponent-selection/README.md) before choosing components.**

All passive component will be separated into two standards: Flight Standard and Prototyping Standard as per the component-selection [README](../../coponent-selection/README.md). Each standard should have drop-in replacements for schematics and PCB gerbers for easy prototype to flight boards transitioning.

First iterations should always be made using prototyping standard components as defined in each passive component selection guide.
